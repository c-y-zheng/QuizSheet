# QuizSheet

一款简单、私密、可完全离线使用的 Excel 刷题工具。

选择一个 `.xlsx` 题库文件，即可在浏览器中进行顺序练习、随机练习和错题复习。题库和答题记录不会上传到服务器，无需注册，也无需下载安装软件。

## 使用方法

1. 下载整个项目目录（不能只下载 `index.html`）。
2. 双击打开 `index.html`。
3. 选择 `Sample_quizsheet.xlsx` 或自己的题库。
4. 选择练习方式；需要时展开“更多练习设置”筛选题量、分类和难度。
5. 点击“开始练习”。

项目已内置 SheetJS，首次使用也不需要联网。

## Excel 格式

程序读取第一个工作表。前三列为必需列：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `题目` | 是 | 题干，也兼容“题干”“问题” |
| `题型` | 是 | 包含“单选”“多选”或“判断” |
| `答案` | 是 | `A`、`AB`、`A,B`、`正确`、`错误` 等 |
| `A`～`H` | 视题型 | 单选/多选至少填写两个选项；无选项的判断题会自动生成正确/错误 |
| `解析` | 否 | 提交答案后显示的说明 |
| `分类` | 否 | 分类、知识点或科目 |
| `难度` | 否 | 题目难度 |

答案字母不区分大小写，支持英文逗号、中文逗号、分号和空格。导入时如有格式问题，页面会显示具体 Excel 行号；有效题目仍可继续使用。

单个题库文件最大 20 MB，最多读取 20,000 行题目。建议只导入来源可信的题库；更大的题库请拆分使用。

## 功能

- 单选题、多选题、判断题
- 顺序练习与随机题序
- 单一主按钮流程：“提交答案 → 查看反馈 → 下一题”
- “不会，查看答案”直接计入错题，避免强制猜测
- 可选答题后自动跳题：单选/判断选择即提交，多选提交后跳题；答错停留时间可在 0～5 秒间设置
- 未选择答案时阻止前进，完成练习前自动检查并定位漏答题
- 按题量、分类和难度筛选，可选随机选项顺序
- 题目解析、分类和难度字段
- 题号导航、答题状态和存疑标记
- 长题干、长选项和长解析独立滚动，操作按钮保持可见
- 错题重练、存疑复习、错题详情和分类表现
- A～H 选项快捷键、Enter 提交/前进、方向键导航
- 导入摘要、重复题检测和具体错误行号
- 浏览器本地保存进度；再次选择同一题库会自动恢复
- 自适应电脑、平板和手机
- 本地解析 Excel，用户内容通过 DOM 文本节点安全渲染
- 无后端、无构建流程、无安装步骤

## 本地进度与隐私

题库只在当前页面内存中读取。浏览器的 `localStorage` 仅保存题目编号、练习设置、作答结果、存疑标记、题序和当前位置，不保存 Excel 文件本身，也不会进行网络请求。

点击结果页的“重新练习”会重置当前答题记录。浏览器隐私模式可能不会长期保留进度。
